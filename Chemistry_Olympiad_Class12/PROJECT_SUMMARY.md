### Step 1: Get Your API Key (2 minutes)
1. Visit https://console.anthropic.com/
2. Sign up (get $5 FREE credit!)

4. Copy it (starts with sk-ant-api03-)

- Download from https://www.python.org/downloads/
- Install Python 3.8 or higher
- ✅ Check "Add Python to PATH"

### Step 3: Install Requirements (1 minute)
```bash
cd Chemistry_Olympiad_Class12
pip install -r requirements.txt
```

### Step 4: Run the Program
**Easiest Method:**
- Windows: Double-click `run.bat`
- Mac/Linux: Double-click `run.sh`

**Alternative:**
```bash
python main.py
```

### Step 5: Start Generating!
1. Enter your API key when prompted
2. Choose option 1 (Generate Questions)
3. Choose option 4 (Quick Start)
4. Wait 30-60 seconds
5. Done! ✅

## 📞 Troubleshooting

### "API key not configured"
→ Main Menu → Option 6 → Enter your key

### "Failed to generate questions"
→ Check internet connection
→ Verify API key is correct
→ Check you have API credits remaining
→ Program auto-retries 3 times

### "Python command not found"
→ Reinstall Python with "Add to PATH" checked
→ Try `python3 main.py` instead

### "Low quality score consistently"
→ Try regenerating the batch
→ Check internet connection stability

### Program closes immediately
→ Don't double-click main.py
→ Use run.bat or run.sh instead
→ Or run from Command Prompt/Terminal
