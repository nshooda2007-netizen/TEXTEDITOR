# Quick Start Guide

## Installation & Setup (5 minutes)

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm start
```

The app will open automatically in an Electron window.

## Create Your First Book (2 minutes)

1. Click **"Create New Book"**
2. Enter title: "My First Book"
3. Select age: "Age 0-7"
4. Click **"Create Book"**

## Add Your First Page (3 minutes)

### Add Text
1. Click the **"Text"** button in toolbar
2. Double-click the text box to edit
3. Type: "Welcome to my book!"
4. Use right sidebar to change font size to 48

### Add an Image
1. Click the **"Image"** button
2. Click the image placeholder
3. Select an image from your computer
4. Drag to reposition, resize using corner handle

### Customize
- Change background color using the color picker
- Add animation from Properties Panel
- Try different fonts (including Hindi!)

## Preview Your Book (1 minute)

1. Click **"Preview"** button
2. Use arrow keys or buttons to navigate
3. Press ESC to exit

## Save & Export (2 minutes)

### Save
- Auto-saves every 30 seconds
- Or click **"Save"** button manually

### Export
1. Click **"Export"** button
2. Choose destination folder
3. Open `index.html` in any browser!

## Tips

- **Drag elements** anywhere on the canvas
- **Delete** selected elements with Delete key
- **Duplicate pages** for consistent layouts
- **Test frequently** using Preview mode
- **Save often** before major changes

## Common Tasks

### Change Text Color
1. Select text element
2. Properties Panel → Text Formatting → Color
3. Pick your color

### Add Background Music
1. Click **"Audio"** button
2. Click audio placeholder
3. Upload MP3 file
4. Position player on page

### Reorder Pages
1. Go to left sidebar
2. Drag page thumbnails up/down
3. Release to reorder

### Delete Elements
1. Click element to select
2. Click red trash icon
3. Or press Delete key
